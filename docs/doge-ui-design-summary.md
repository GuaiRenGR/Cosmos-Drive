# DogeUI 系列项目 UI 设计总结

## 概述

DogeUI 是基于阿里云 IoT 小程序框架（HaaS UI / Falcon 框架）构建的三个开源应用项目：**doge-calculator（计算器）**、**doge-comic（漫画阅读器）**、**doge-reader（电子书阅读器）**。所有项目均使用 Vue.js 2.6 语法 + Less 样式，通过 Falcon 框架的 W3C 标准标签子集渲染 UI。

三个项目共享一套高度一致的 UI 设计语言，但在色彩体系和布局细节上各有侧重。

---

## 一、色彩体系

### 1.1 doge-calculator（深色单主色方案）

| 变量 | 色值 | 用途 |
|------|------|------|
| `@primary` | `#1a1b1f` | 主背景/卡片底色 |
| `@on-primary` | `#e3e3e3` | 主色上的文字 |
| `@link` | `#0842a0` | 链接色 |
| `@neutral` | `#8e918f` | 中性文字/标题 |

**特点**：极简的二色阶方案，仅 4 个颜色变量，以深灰黑 `#1a1b1f` 为唯一背景，浅灰白 `#e3e3e3` 为文字色，整体风格冷峻、克制。

### 1.2 doge-comic & doge-reader（Material You 风格六色方案）

| 变量 | 色值 | 用途 |
|------|------|------|
| `@primary` | `#004a77` | 主色调（深蓝） |
| `@on-primary` | `#c2e7ff` | 主色上的文字 |
| `@neutral` | `#1a1b1f` | 卡片/中性背景 |
| `@on-neutral` | `#e3e3e3` | 中性背景上的文字 |
| `@secondary` | `#7a0f1c` | 次要色（深红） |
| `@on-secondary` | `#ffd6db` | 次要色上的文字 |
| `@link` | `#0842a0` | 链接色 |
| `@surface` | `#080a0c` | 表面/底层背景 |
| `@outline` | `#8e918f` | 轮廓/次要文字 |

**特点**：comic 和 reader 共享完全相同的色彩变量表，构成了类似 Material You 的语义化色彩体系。`@primary` 深蓝 `#004a77` 作交互强调，`@secondary` 深红 `#7a0f1c` 作辅助/警告强调，`@surface` 极致黑 `#080a0c` 作页面底色，形成清晰的层级关系。

## 二、页面布局模式

### 2.1 通用布局：左侧导航栏 + 右侧内容区

三个项目均采用 **左侧固定宽度导航栏（ButtonColumn）+ 右侧弹性滚动内容区** 的经典布局：

```
┌──────────┬──────────────────────────────┐
│          │                              │
│ 返回按钮  │                              │
│          │         scroller             │
│ 设置按钮  │       (flex: 1)              │
│          │                              │
│   ...    │                              │
│          │                              │
└──────────┴──────────────────────────────┘
```

- **ButtonColumn**：固定宽度 `33vh`，垂直排列操作按钮，上下留白，高度 `100vh`
- **右侧内容区**：`flex: 1`，可滚动，通过 `scroller` 标签实现

### 2.2 卡片式内容布局

所有内容均以圆角卡片形式呈现，卡片间距统一为 `4-7vh`：

- 文件列表卡片：`border-radius: 6vh`，`padding: 3vh 7vh`
- 设置卡片：`border-radius: 8vh`，`padding: 8vh`
- 信息卡片：`border-radius: 8vh`，`padding: 8vh 12vh`

### 2.3 侧边抽屉（Drawer）

comic 和 reader 均使用右侧滑出抽屉（Drawer）来承载阅读设置/章节导航：

- 宽度 `75vw`，从右侧 `translateX(100%)` 滑入
- 半透明遮罩层 `rgba(0,0,0,0.4)`
- 过渡动画 `0.3s ease-in-out`

## 三、组件体系

### 3.1 通用组件（三个项目共享）

| 组件 | 功能 | 样式特征 |
|------|------|----------|
| `ButtonColumn` | 左侧导航栏容器 | 固定宽度 33vh，圆角按钮排列 |
| `IconButton` | 图标按钮 | 22vh 方形，圆角 7vh，60% 图标尺寸 |
| `InfoCard` | 信息展示卡片 | 水平排列，左侧标签 + 右侧值 |
| `Toast` | 轻提示 | 全局事件驱动 |

### 3.2 计算器独有组件

| 组件 | 功能 | 样式特征 |
|------|------|----------|
| `Button` | 计算器按键 | flex 1 等分，圆角 5vh，双向色（背景色+文字色） |
| 键盘布局 | 3 行功能键 + 数字键 | 高度 70vh，等分 3 行 |

### 3.3 阅读器（comic + reader）共享组件

| 组件 | 功能 | 样式特征 |
|------|------|----------|
| `FileCard` | 文件/文件夹条目 | 图标 + 文件名 + 大小，圆角 6vh |
| `HistoryCard` | 历史记录条目 | 文件名 + 时间，圆角 6vh |
| `SettingCard` | 设置项卡片 | 标题 + 描述 + 右侧控件 |
| `Toggle` | 开关控件 | 32vh×18vh，Material 风格滑轨+滑块 |
| `SeekbarCard` | 滑块调节卡片 | 标签 + 数值 + seekbar |
| `Drawer` | 右侧抽屉 | 75vw 宽度，滑入动画 |
| `PageTurningButton` | 翻页按钮 | 24vh 高度，图标 + 文字 |

### 3.4 功能模块独有组件

| 组件 | 所属项目 | 功能 |
|------|----------|------|
| `ComicCard` | comic | 漫画封面缩略图，自动提取首张图片 |
| `IndexButton` | comic | 首页入口按钮，图标 + 文字水平排列 |
| `MainButton` | reader | 首页大按钮，图标纵向 + 文字，填充整个 flex 容器 |
| `MenuCard` | reader | 章节菜单项，支持 active 高亮 |

## 四、交互设计

### 4.1 统一的交互模式

- **按下反馈**：所有可点击元素均通过 `:active { opacity: 0.6 }` 提供按压反馈
- **返回导航**：统一使用 `$falcon.navTo()` 和 `$page.finish()` 进行页面跳转
- **物理返回键**：阅读器页面拦截系统返回键（`backpressed` 事件），实现自定义返回逻辑（保存进度后退出）
- **空状态**：列表为空时居中显示"什么也没有哦..."提示文字
- **加载状态**：使用 `loading` 变量控制加载态，显示"少女祈祷中..."文字

### 4.2 设备适配

- 使用 `$falcon.env.deviceWidth` 和 `deviceHeight` 动态计算布局尺寸
- 所有尺寸使用 `vh`（视口高度百分比）单位，天然支持多分辨率
- comic 首页封面网格根据屏幕宽度动态计算列数

### 4.3 持久化

- 所有项目使用统一的 `Storage` 工具类（基于 KV 存储）
- 阅读进度、设置项、收藏列表等在 `onHide` 时自动保存

## 六、设计原则总结

1. **语义化色彩**：使用 Material You 风格的 token 命名（primary / on-primary / neutral / surface），每种颜色承担明确的语义角色
2. **暗色主题优先**：所有项目默认深色背景，适合嵌入式设备屏幕和低光环境使用
3. **vh 单位自适应**：全部尺寸使用视口高度百分比，天然适配不同分辨率和屏幕比例
4. **卡片化设计**：内容以圆角卡片组织，层次清晰，间距统一
5. **组件复用**：comic 和 reader 共享大量组件（ButtonColumn、IconButton、FileCard、Drawer、Toggle、SeekbarCard、SettingCard、PageTurningButton、Toast），代码复用率高
6. **功能聚焦**：每个应用专注解决一个核心场景（计算/看漫画/读书），页面结构简洁，信息层级扁平
