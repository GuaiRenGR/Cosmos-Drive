# 开发环境

### <font style="color:rgb(55, 61, 65);">Windows系统开发环境安装问题</font>
#### <font style="color:rgb(55, 61, 65);">脚手架无法安装问题</font>
<font style="color:rgb(55, 61, 65);">在Windows系统上部署开发环境是，存在脚手架无法装问题</font>

+ <font style="color:rgb(55, 61, 65);">vscode装机完毕后，cmd命令把前期部署的都搞完</font>
+ <font style="color:rgb(55, 61, 65);">手脚架无法安装问题：解决办法：cnpm install -g request semver prompts pump，验证办法：aiot-cli -V出版本号</font>

#### <font style="color:rgb(55, 61, 65);">模拟器路径配置</font>
<font style="color:rgb(55, 61, 65);">模拟器配置设置地址，一定要指向虚拟机路径下.exe上一层的地址</font>

#### <font style="color:rgb(55, 61, 65);">部署完相关项目后选择编译和执行后，一直让重试</font>
+ <font style="color:rgb(55, 61, 65);">建议在vsxode终端切换cmd命令，执行aiot-cli simulator --simpath C:\Users\issuser\Downloads\haasui-simulator-windows-64，这个地址选择demo虚拟机的地址</font>
