# 云端文件选择接口

Cosmos Drive 提供一个给其他 Falcon mini-app 使用的“系统文件选择器”接口。

例如小说阅读软件需要导入 TXT 时，调用方只需跳转到 Cosmos Drive。词典笔上会打开 Cosmos Drive 的 WebDAV/FTP 文件浏览页；用户点选一个远程文件并确认后，Cosmos Drive 自动下载文件到本地目录，再跳回小说阅读软件并返回本地文件路径。调用方不需要引入 Cosmos Drive 的 JavaScript 模块、`.so` 或其他库。

## 接口地址

```text
应用 ID：8001787877932650
页面：picker（兼容地址：index）
URI：falcon://8001787877932650/picker
```

调用依赖 Falcon 内置的 `$falcon.navTo` 和页面参数生命周期。

## 发起选择

调用方在自己的页面中生成一个本次唯一的 `requestId`，然后跳转：

```javascript
const requestId = 'reader-import-20260828-001'

$falcon.navTo('falcon://8001787877932650/picker', {
  action: 'select-file',
  requestId,
  returnUri: 'falcon://9000000000000001/index',
  downloadDir: '/userdisk/Favorite/my-reader/imports',
  downloadName: 'book.txt'
})
```

如果不需要自定义文件名，可以省略 `downloadName`。如果不传 `downloadDir`，Cosmos Drive 使用：

```text
/tmp/cosmos-drive-select/<requestId>/文件名
```

调用方收到结果后即可读取 `file.localPath`。临时目录可能在设备重启后清理，需要长期保存时应传入调用方自己的目录或共享目录。

选择文件夹时，将 `action` 改为 `select-folder`：

```javascript
$falcon.navTo('falcon://8001787877932650/picker', {
  action: 'select-folder',
  requestId: 'reader-import-folder-20260828-001',
  returnUri: 'falcon://9000000000000001/index',
  downloadDir: '/userdisk/Favorite/my-reader/imports'
})
```

### 请求字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `action` | string | 是 | `select-file` 或 `select-folder`。 |
| `requestId` | string | 是 | 调用方生成的唯一 ID。只允许 ASCII 字母、数字、`.`、`_`、`:`、`-`，最长 128 个字符。 |
| `returnUri` | string | 是 | 接收结果的 Falcon URI，必须以 `falcon://` 开头，最长 512 个字符。可以是应用 ID URI，也可以是已注册的唯一 Category URI。 |
| `downloadDir` | string | 否 | 文件下载目录。必须是绝对路径，并位于 `/tmp/`、`/userdisk/` 或 `/userdata/` 下，最长 480 个字符。Cosmos Drive 会在该目录下建立 `<requestId>` 子目录。 |
| `downloadName` | string | 否 | 仅用于 `select-file` 的目标文件名，不得包含 `/` 或 `\\`，最长 240 个字符。省略时使用远程文件名。 |

`downloadDir` 可以是调用方的私有目录，也可以是双方约定的共享目录。目录需要对 Cosmos Drive 所在运行用户可写；不可写时会返回 `download-failed`。接口不会返回连接密码。

## 词典笔上的操作

### 选择文件

页面标题显示“选择文件”。用户可以切换已配置的 WebDAV 或 FTP 连接、进入文件夹，然后点击文件条目选中它，再点击顶部“确认”。Cosmos Drive 会执行下载，下载完成才返回调用方。

### 选择文件夹

页面标题显示“选择文件夹”。进入目标文件夹后点击“选择此文件夹”。文件夹不会递归下载，结果只包含远程文件夹路径。

### 取消

点击“取消”会返回 `cancelled: true`。远程列表失败、下载失败等可处理错误也会返回调用方，不会让调用方无限等待。

## 返回结果

结果通过 `returnUri` 的页面参数传递。所有结果都包含：

```javascript
{
  source: 'cosmos-drive',
  version: 1,
  requestId: 'reader-import-20260828-001',
  action: 'select-file',
  cancelled: false
}
```

### 文件下载成功

```javascript
{
  source: 'cosmos-drive',
  version: 1,
  requestId: 'reader-import-20260828-001',
  action: 'select-file',
  cancelled: false,
  file: {
    name: '中文笔记.txt',
    rawName: '%E4%B8%AD%E6%96%87%E7%AC%94%E8%AE%B0.txt',
    path: '/notes/%E4%B8%AD%E6%96%87%E7%AC%94%E8%AE%B0.txt',
    localPath: '/userdisk/Favorite/my-reader/imports/reader-import-20260828-001/book.txt',
    downloaded: true,
    folder: false,
    size: 4096,
    modTime: 'Tue, 27 Aug 2026 12:00:00 GMT',
    connection: {
      name: '家庭 NAS',
      type: 'WebDAV',
      host: '192.168.1.20:5005'
    }
  }
}
```

`file.localPath` 是调用方应该直接读取的本地路径；`file.path` 是远程路径。Cosmos Drive 会对 WebDAV/FTP 返回的 URL 编码文件名解码到 `name`，同时保留原始名称在 `rawName`。如果目标文件已存在，会自动追加 `_1`、`_2` 等后缀，不覆盖已有文件。

### 文件夹选择成功

```javascript
{
  source: 'cosmos-drive',
  version: 1,
  requestId: 'reader-import-folder-20260828-001',
  action: 'select-folder',
  cancelled: false,
  file: {
    name: '备份',
    rawName: '',
    path: '/备份',
    folder: true,
    size: 0,
    modTime: '',
    connection: {
      name: '家庭 NAS',
      type: 'WebDAV',
      host: '192.168.1.20:5005'
    }
  }
}
```

文件夹结果没有 `localPath`，因为接口不会下载文件夹内容。

### 取消或错误

```javascript
{
  source: 'cosmos-drive',
  version: 1,
  requestId: 'reader-import-20260828-001',
  action: 'select-file',
  cancelled: true,
  error: {
    code: 'cancelled',
    message: '用户取消选择'
  }
}
```

当前错误代码包括：

| `error.code` | 含义 |
| --- | --- |
| `cancelled` | 用户主动取消。 |
| `remote-error` | 无法读取远程目录。 |
| `download-failed` | 远程文件下载失败、本地目录不可写或文件名无效。 |

调用方必须先核对 `source`、`version` 和自己的 `requestId`，再判断 `cancelled`，最后读取 `file.localPath` 或 `file.path`。未知字段应忽略，以兼容未来版本。

## 调用方接收示例

Vue 根组件可以在 `onShow` 中读取首次启动参数 `loadOptions` 和重新唤起参数 `newOptions`。这是最少改动的方式，因为 Falcon 的页面基类会在页面显示时调用根组件的 `onShow`：

```javascript
export default {
  data() {
    return { pendingRequestId: '', importedPath: '' }
  },
  methods: {
    openCloudFile() {
      this.pendingRequestId = 'reader-import-' + Date.now()
      $falcon.navTo('falcon://8001787877932650/index', {
        action: 'select-file',
        requestId: this.pendingRequestId,
        returnUri: 'falcon://9000000000000001/index',
        downloadDir: '/userdisk/Favorite/my-reader/imports'
      })
    },
    handleCosmosDriveResult(options) {
      if (!options || options.source !== 'cosmos-drive' || options.version !== 1) return
      if (options.requestId !== this.pendingRequestId) return
      this.pendingRequestId = ''
      if (options.cancelled) {
        this.showToast(options.error && options.error.message || '选择失败')
        return
      }
      if (!options.file || options.file.folder || !options.file.localPath) return
      this.importedPath = options.file.localPath
      this.importTextFile(this.importedPath)
    },
    onShow() {
      const page = this.$page
      if (!page) return
      this.handleCosmosDriveResult(page.loadOptions)
      this.handleCosmosDriveResult(page.newOptions)
    }
  }
}
```

如果调用方需要在 `onNewOptions` 生命周期立即处理结果，可以在自己的页面类中转发：

```javascript
onNewOptions(options) {
  super.onNewOptions(options)
  if (this.$root && this.$root.handleCosmosDriveResult) {
    this.$root.handleCosmosDriveResult(options)
  }
}
```

## 原生模块和兼容性

Cosmos Drive 自己仍通过私有的 `cosmos_drive` JSAPI 和 ARMv7 核心访问 WebDAV/FTP。原生模块不会暴露给调用方；调用方不应导入 `cosmos_drive`，也不需要打包 `libjsapi_cosmos_drive.so`。调用方只使用 Falcon 容器内置的 `$falcon.navTo`。

接口使用应用间 `navTo` 和 `loadOptions/newOptions`，不使用 `$falcon.trigger`，因为全局事件只作用于当前应用。当前仓库没有词典笔真机，安装后仍需在目标固件上验证应用间跳转、下载目录权限和返回参数生命周期。
