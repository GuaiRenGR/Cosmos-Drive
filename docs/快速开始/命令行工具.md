# 命令行工具

# 终端命令行方式
通过aiot-cli 和 npm命令进行应用创建、编译以及运行，支持的命令如下(安装见[链接](https://www.yuque.com/wcye0k/haasui/lytxwk))：

| **<font style="color:rgb(52, 73, 94);">命令</font>** | **<font style="color:rgb(52, 73, 94);">说明</font>** | **<font style="color:rgb(52, 73, 94);">其他</font>** |
| --- | --- | --- |
| **<font style="color:rgb(25, 137, 250);">aiot-cli create [name]</font>** | 创建应用工程 | 通过命令行创建应用新工程 |
| **<font style="color:rgb(25, 137, 250);">cnpm run build</font>** | <font style="color:rgb(52, 73, 94);">编译Debug包</font> | <font style="color:rgb(52, 73, 94);">不会混淆JS文件，方便排查和调试，开发阶段推荐(性能会差 且 内存开销大)</font> |
| **<font style="color:rgb(25, 137, 250);">cnpm run build:prod</font>** | <font style="color:rgb(52, 73, 94);">编译Release包</font> | 会混淆JS文件，正式版推荐 |
| **<font style="color:rgb(25, 137, 250);">cnpm run build:simulator</font>** | <font style="color:rgb(52, 73, 94);">模拟器预览</font> | <font style="color:rgb(52, 73, 94);">电脑运行模拟器，推荐使用vscode</font>[开发插件](about:blank) |


### 应用创建
aiot-cli create [name] #创建工程，name为你的工程名 

cd [name]              #进入到该工程的目录中 

cnpm install           #安装应用依赖

### 终端命令行操作
#### 应用编译(打包构建)
+ 在工程目录下面，输入编译命令
+ 编译debug测试应用包

cnpm run build      #编译Debug测试应用包

+ 编译release 正式应用包

cnpm run build:prod   #编译release 正式应用包

+ 打包成功，同时会在工程路径下生成/.falcon_/ 文件资源，以及 /.falcon_/{appId}.amr应用包
