# Cosmos Drive 电脑端配置说明

词典笔上的连接配置文件位于：

```text
/userdisk/Favorite/cosmos/drive/connections.json
```

可以在电脑上编辑该文件，再将它复制回词典笔。建议先退出 Cosmos Drive，复制完成后再启动应用。

首次启动 Cosmos Drive 时，核心服务会自动创建目录和配置文件；初始内容为 `[]`。如果文件已经存在，启动不会覆盖它。词典笔端点击“添加连接”后，核心服务会以 `0600` 权限更新同一个文件，因此电脑端和词典笔端使用的是同一份配置。

## 文件格式

文件内容是 JSON 数组，每个连接一个对象：

```json
[
  {
    "type": "WebDAV",
    "name": "家庭 NAS",
    "host": "192.168.1.20:5005",
    "user": "alice",
    "password": "change-me",
    "basePath": "/dav",
    "tls": true
  },
  {
    "type": "FTP",
    "name": "局域网 FTP",
    "host": "192.168.1.30:21",
    "user": "alice",
    "password": "change-me",
    "basePath": "/home/alice",
    "tls": false
  }
]
```

字段说明：

- `type`：只能是 `WebDAV` 或 `FTP`。
- `name`：词典笔界面显示的连接名称，必须唯一。
- `host`：主机名或 IP，可带端口；FTP 默认端口为 `21`。
- `user`、`password`：服务端账号。密码会以明文保存在设备文件中，请设置文件权限为 `0600`，并避免把配置文件提交到代码仓库。
- `basePath`：远程根路径，留空时使用 `/`。
- `tls`：WebDAV 使用 HTTPS 时设为 `true`；FTP 当前使用明文被动模式，必须设为 `false`。

## 电脑端检查清单

1. 使用 UTF-8 保存，不能带注释、尾逗号或 BOM。
2. JSON 顶层必须是数组。
3. `name`、`host`、`type` 不能为空。
4. 先备份原文件，再替换目标文件。
5. 设备上首次打开连接后，点击刷新验证目录读取；上传、下载前确认设备有足够空间。

## 词典笔端配置

在“连接”面板点击“添加连接”，选择 WebDAV 或 FTP，填写名称、服务器地址、用户名和密码后保存。应用会通过本地核心服务写入上述文件，并重新加载连接列表。

应用还会通过 Falcon `storage` 模块保存界面状态（当前连接、排序和 Wi-Fi 设置），键名为 `cosmos-drive.state`。这部分是应用私有的键值存储，不替代上面的连接配置文件；清除应用键值不会删除远程连接文件。

## 文件传输

文件浏览页默认显示远程目录中的全部文件。点击“本地文件”后，应用会使用 Falcon `fs` 接口浏览 `/userdisk/Favorite` 下的本地目录；进入目录并点击普通文件即可选中它。返回远程浏览页后才会显示“上传”按钮，上传目标是当前远程目录。

远程文件的更多菜单中的“下载到本机”会把文件保存到：

```text
/userdisk/Favorite/cosmos/drive/downloads/
```

该目录会在首次下载时自动创建。文件名沿用远程文件名；如果同名文件已经存在，下载会覆盖原文件，建议下载前检查目录内容。

配置页使用 Falcon `<input>` 组件，并在目标固件提供 `global` 模块时调用 `Global.startTextEdit`：输入框聚焦会创建带 UUID 的系统输入法会话，`textEditFinished` 仅接受当前会话的确认结果，完成后立即关闭会话。若固件没有该模块或调用失败，则回退到 `<input softInputEnable="true">` 的内置软键盘路径。输入框支持普通文本和密码两种模式。
