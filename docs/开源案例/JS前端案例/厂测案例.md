## 简单讲解
该示例用于产测程序中触摸屏校验，可根据自身屏幕特征调整参数。



可修改参数：

+ 设备宽高：修改 deviceWidth deviceHeight
+ 触摸精度：修改 CHECK_精度px
+ 配置更多测试条：steps
