### 示例代码

```vue
<latex style="font-size: 80px;" value="\sum_{i=0}^n(x_i^2+y_j^3)"/>
```

## 简介

`<latex>` 组件，用来渲染latex排版系统，可用于数学公式等场景

`<latex>` 不支持子组件。

语法参考：<http://www.uinio.com/Math/LaTex/>

**<font style="color:#DF2A3F;">tip：该组件需要框架版本为V1.6版本</font>**

## 样式

* 支持 **通用样式**。
* 支持 **文本样式**。
  * font-size
  * line-spacing
  * color

## 事件
