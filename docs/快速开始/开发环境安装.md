# 开发环境安装

### 安装NodeJS(必须)
+ [英文官网](https://nodejs.org/)，建议版本v16+或更高
+ [中文官网下载](https://www.nodejs.com.cn/)
+ 安装后系统具有 node/ npm 两个命令
+ <font style="color:rgb(64, 64, 64);">查看nodejs版本号，在终端中输入：</font>**<font style="color:rgb(64, 64, 64);"></font>**

```plain
node -v
```

tip: NodeJS 版本建议16 稳定版本即可，具体可以[访问官网](https://nodejs.org/zh-cn/)



+ 查看npm版本号，<font style="color:rgb(64, 64, 64);">在终端中输入</font>：

```plain
npm -v
```

+ [NodeJS教程](https://www.runoob.com/nodejs/nodejs-tutorial.html)(仅参考)
+ [npm教程](https://www.runoob.com/nodejs/nodejs-npm.html)(仅参考)

### 安装cnpm(推荐)
+ <font style="color:rgb(64, 64, 64);">由于npm服务器不在国内，所以有时下载JS包时速度会慢一点，建议安装一下</font>**<font style="color:rgb(64, 64, 64);">cnpm</font>**<font style="color:rgb(64, 64, 64);">命令</font>
+ <font style="color:rgb(64, 64, 64);">安装命令：</font>

```plain
sudo npm install -g cnpm --registry=https://registry.npmmirror.com
```

```plain
npm install -g cnpm --registry=https://registry.npmmirror.com
```

+ 查看cnpm版本号，<font style="color:rgb(64, 64, 64);">在终端中输入</font>：**cnpm -v** 
+ <font style="color:#E8323C;">后面可以用</font>**<font style="color:#E8323C;">cnpm</font>**<font style="color:#E8323C;"> 命令替代 </font>**<font style="color:#E8323C;">npm</font>**

### 安装VSCode 开发IDE(推荐)
+ JS前端开发推荐安装VSCode
+ [官网地址](https://code.visualstudio.com/)，推荐在官网下载
+ MacOS系统stable版本国内加速[下载地址](https://vscode.cdn.azure.cn/stable/899d46d82c4c95423fb7e10e68eba52050e30ba3/VSCode-darwin-universal.zip)
+ Window系统stable本国内加速[下载地址](https://vscode.cdn.azure.cn/stable/899d46d82c4c95423fb7e10e68eba52050e30ba3/VSCodeUserSetup-x64-1.63.2.exe)
+ Linux 系统stable deb 国内加载[下载地址](https://vscode.cdn.azure.cn/stable/899d46d82c4c95423fb7e10e68eba52050e30ba3/code_1.63.2-1639562499_amd64.deb)

### 安装框架脚手架
框架脚手架提供项目创建、构建Debug & Release包、运行模拟器等能力

```plain
sudo cnpm i aiot-vue-cli -g     //-g 表示全局安装，必须输入
```

```plain
cnpm i aiot-vue-cli -g     //-g 表示全局安装，必须输入
```

+ 查看aiot-cli版本号，<font style="color:rgb(64, 64, 64);">在终端中输入</font>:   

```plain
aiot-cli -V     //大写的V
```

+ windows系统：如果无法打印版本，需要配置环境变量
+ tip：强制安装某个版本，**<font style="color:#DF2A3F;">建议走上面统一安装方案，不要指定版本号</font>**

```javascript
cnpm install -g aiot-vue-cli@1.0.28  //当前cli最新版本我1.0.28
```

> 如果运行cli出现错误：Error: Cannot find moudle 'request'
>
> 可以尝试运行命令修复：cnpm install -g request semver prompts pump
>

### 删除框架脚手架
```javascript
cnpm uninstall aiot-vue-cli
```
