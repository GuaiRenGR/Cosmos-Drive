# 产品和设备管理

# 一、背景介绍
HaaS云服务控制台（以下简称“控制台”）上的产品，即代表一类设备，这些设备的Product Key、HaaS固件、管理运维策略完全相同。



# 二、创建产品
创建产品之前，首先应申请成为正式用户。游客用户不允许创建产品。

1、 点击导航栏“设备管理”标签下的“产品”标签，打开产品管理界面。

![1614916591379-14f491ba-af5b-401b-ba89-42a0231cd25f.png](./img/www38ySZeQQPeTOw/1614916591379-14f491ba-af5b-401b-ba89-42a0231cd25f-891198.png)

2、 产品管理界面中点击“创建产品”，打开创建产品页。

![1625032288864-94a25dab-eff9-4289-b860-403e7967fc69.png](./img/www38ySZeQQPeTOw/1625032288864-94a25dab-eff9-4289-b860-403e7967fc69-924976.png)

3、 填写产品名称、备注等信息，点击“确认”，即可完成产品创建。

![1618210572735-baad1164-a681-4ca2-8a3d-1b93e952f23a.png](./img/www38ySZeQQPeTOw/1618210572735-baad1164-a681-4ca2-8a3d-1b93e952f23a-269449.png)

创建产品后，即可在产品列表中看到新创建的产品，并可以查看产品详情、编辑产品信息、管理设备。

![1614916591874-adb4591d-97a2-485b-a3cc-fb7e691cc443.png](./img/www38ySZeQQPeTOw/1614916591874-adb4591d-97a2-485b-a3cc-fb7e691cc443-193821.png)

# 三、创建设备
创建设备的本质是在平台上申请设备的三元组（Product Key、Device Name、Device Secret）。

一个设备对应一个三元组。

游客用户可以在平台预先分配的产品下创建2个新设备，如需更多设备，请向HaaS团队申请。

正式用户可以创建正式产品，正式产品默认可创建50个设备，供开发、测试和试产。

操作步骤：

1、 打开分发平台，点击导航栏“设备管理”标签组下的“设备”标签

![1625032256211-db10652c-bc84-4a30-abe5-427147f8cfab.png](./img/www38ySZeQQPeTOw/1625032256211-db10652c-bc84-4a30-abe5-427147f8cfab-637536.png)

2、 申请设备有三种方式，分别为添加设备、批量添加-设备名称随机、批量添加-指定设备名称，可根据自己业务需要选择添加方式。需要注意的是批量添加的设备是异步执行，如果一次申请很多，设备不会立刻全部生成完毕，您可以在设备批次页中查看你申请的进度。

a>添加设备，是添加一个您自己指定设备名称的设备，具体操作如下图所示。

![1625032149711-b09e8226-b90c-44dc-86ed-bc36fcd2134c.png](./img/www38ySZeQQPeTOw/1625032149711-b09e8226-b90c-44dc-86ed-bc36fcd2134c-782873.png)

b>批量添加-设备名称随机，只填写要申请的设备数量即可，操作下图所示。

![1625032219902-5be8205d-9989-43cd-93c0-125be1efd073.png](./img/www38ySZeQQPeTOw/1625032219902-5be8205d-9989-43cd-93c0-125be1efd073-338975.png)

c>批量添加-指定设备名称，上传一个包含设备名称的txt文件，文件中一行代表一个设备名称，请注意文件中不要有标点符号。操作步骤如下图所示。

![1625031985351-51438e29-0b41-41aa-a7da-07b533442d17.png](./img/www38ySZeQQPeTOw/1625031985351-51438e29-0b41-41aa-a7da-07b533442d17-984756.png)

3、创建设备后，您可以在设备列表中点击右侧“查看”，打开设备详情页。

![1614916592573-f3e2cb43-4e22-4c59-b020-0eeabd1327cb.png](./img/www38ySZeQQPeTOw/1614916592573-f3e2cb43-4e22-4c59-b020-0eeabd1327cb-807497.png)

设备详情页包括设备的产品（Product Key）、设备名（Devicve Name）和设备密钥（Device Secret），将这些信息写入HaaS板，就可以在HaaS板上体验云端能力了。

# 四、重置设备
<font style="color:rgb(51, 51, 51);">如果直连设备通过动态注册(一型一密)方式获取设备证书信息（ProductKey、DeviceName和DeviceSecret）并激活后，无法再通过动态注册获取设备证书信息，可以通过设备管理->批量重置(批量上传重置设备)功能重置后获取新的设备认证信息。</font>

**<font style="color:#f5222d;">注意</font>**<font style="color:rgb(51, 51, 51);">：该方式仅适用在HaaS控制台创建的一型一密动态注册产品，非一型一密及从物联网平台绑定的产品不支持此操作。</font>

![1630290466012-40d603fc-8e17-4244-8500-7558f9dfb748.png](./img/www38ySZeQQPeTOw/1630290466012-40d603fc-8e17-4244-8500-7558f9dfb748-970016.png)

批量上传重置功能可以使用txt文件保存每个设备deviceName后一次性上传重置，支持单产品单次最多1000个设备，空行会自动过滤不计

![1630290610755-c5907bb4-6ce1-483c-89be-05fec082b85c.png](./img/www38ySZeQQPeTOw/1630290610755-c5907bb4-6ce1-483c-89be-05fec082b85c-177467.png)

操作完成后，可以在批量重置批次中查看到每个设备的重置结果

![1630291005701-2bedf33b-2f04-4d10-bcc6-0003bccf574a.png](./img/www38ySZeQQPeTOw/1630291005701-2bedf33b-2f04-4d10-bcc6-0003bccf574a-358086.png)
